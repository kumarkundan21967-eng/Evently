# 🎫 Evently - Event Management System

Evently is a full-stack online event management system that allows users to create, manage, discover, and book events through a simple web interface.

## 🚀 Live Demo

https://evently-production-b57e.up.railway.app/

## ✨ Features

### 👨‍💼 Admin
- Manage users
- Manage events
- Approve pending events
- View dashboard statistics
- Manage system settings

### 🎤 Organizer
- Create events
- Manage events
- Add ticket information
- Track event details

### 👤 Attendee
- Browse events
- Register for events
- Purchase tickets
- View My Tickets
- View registration history
- Receive notifications
